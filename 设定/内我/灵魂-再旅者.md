# 再旅者 设定案

剧情版内容请参见(`回归点`)

源石是“接口”与“语言”，而后者的表达不完备。“语言”无法完备描述一个“灵魂”，因此对于再旅者与重生，应该存在三种途径：

- 复生：

  真正的源石灵魂重引用，完整重生行为。灵魂本身为全量高维连续对象，每个维度上都存在一个自指奇点。该智能结构被称为高维连续态智能体。

- 再旅：

  源石内化数据库中信息完备解压，得到一个具有等效智能的独立个体。（不完备低维连续对象。由于其连续性，完备解压本身会损坏原始数据自指奇点。但是仍然可以对其进行投影，得到不连续体）。该智能结构被称为低维连续态智能体。

  在灰山事件后，由于源石的概念性破缺，在超域作用下，源石与灵魂之海发生界面相交，形成了一大批存在严重问题的实体元素，同时暴露了对应的信息接口。

- 投影：

  源石内化数据库中信息的不完备解压，我暂且称之为“再投影”/“记忆性拟合”，得到一个知晓过去，但缺乏主观性的空壳实体。（不连续对象，记忆性拟合）该智能体结构被称为超越型离散态智能体。

- 此外，我们在此一同定义：对于机器学习的传统形式智能结构，称为机械型离散态智能体。

同样，基于源石的语言性质，不难推出，如果需要通过某种途径完备表达“灵魂”的实例，那现存的“源石”的语言体系是不充分的。

需要注意的是：“是否拥有灵魂”这件事本身不代表“实体是否具有自我锚定”或“实体是否能被认为具有人格，个体性与价值”。
对于前者，通常而言再旅者通过重拟合也能具有自我锚定，只是通常与原始实体不完全相同，离散态智能体也能初步理解“自我”概念的本身，只是无法进入深入的内源探讨。
对于后者，则完全基于社会关系，通过社会中其它个体的评判来决定。从这一角度而言，是否具有智能本身都与该问题无直接关联。

## 专有名词

### 灵魂之海/灵域

（原设）死亡之后，灵魂完全回归的地方，永恒的静态。

灵魂，或被称为“灵魂智能结构”。

所有生命全部都是灵魂之海中自身的引用，如果引用可以实现，则可以完全以“自己”复活。 引用本身不可被同时指向两个实体。

在原设中，死魂灵曾堆积在源石概念域与灵魂之海的交界面上，特蕾西娅在清除这些死魂灵后，二者被隔离开。

### 完备自我

通常认为，灵魂之海中的灵魂具有对自指的完全处理能力，因此具有完备自我。

完备自我本身无法被用语言体系完备表述，语言体系中一旦出现自指元就会引发循环自指崩溃。

设定上，在末期，文明发明了一种可以正确处理自指元的方案（自指偏移与投影联立），使得自我本身能被以一种无法理解的方式完备表述。

### 源石灵体分区/内化宇宙灵域

见“源石”设定案。

所有与源石有关的人都会被记录，记忆会被按照注意力堆叠，而个性则会随着灵魂的变化不断被投影备份。

正常情况下，这种备份在实体时会执行一次自回归，用于处理投影导致的边缘逻辑坏死。

在分区中，每个实体的备份被称为一个`智能片元`。

### 切面/源石森林

在“死愿”事件中，博士丧生。起源源石部分逆转了这一事件，同时也造成了源石本身的概念性破缺。博士在天使战争进入反攻阶段时第一次“死亡”。

在“暴乱”事件中，起源源石所处的位置被巨大的侵蚀潮冲击，这直接导致了超域影响源石。

这种错误的物质化引发了源石概念空间与灵魂之海结构的相交(这个交界面也就是死魂灵之前堆积的区域)
，而这个相交切面发生了某种类似“结晶”的反应，形成了一层高维信息元素层，包含了大量错误的实体信息。

这一部分即为“切面”或“源石灵体分区坏死切面”，即“源石森林”。

### 减量崩溃

源石与灵魂之海的碰撞引发了严重后果：静态的灵魂被源石强行且缓慢地降维投影成单奇点元素，而源石本身在对它们进行不断的推演。

这种推演可能来自设计缺陷：对灵魂之海中的灵魂，源石没有对于自指奇点的过滤，这使得它们极难被拟合为稳定态；由于缺失中断机制，这种近乎酷刑的演化会被一直执行，直到内生崩溃或过拟合。

这导致这部分灵魂需要承受某种“撕裂性的痛苦”，伴随着感知像素化/思维减除/去实体化/自我离散等一系列严重问题。

大部分灵魂在其中变得极端，崩溃或退化（与智能退化设定类似，见[`流放者`设定案](../../骨架-Exile.md#内生智能)）。
简而言之，这一部分包含降维，离散化，以及实体在撕裂环境下被强行自蒸馏的极度痛苦，最终产生危险而崩溃的智能片元。

### 灵体分区驳接口

并非某个实体层面存在的地点，但能允许实体在特定条件下切入，通向某种源石森林的映射域。

该空间具有索拉里斯性，而末端的源石森林则属于非欧空间。不过考虑到在其中遭遇意外的实体通常会被直接安全排出内化空间，其危害性相对较小。

通过这一接口与下面的实体解压技术，再旅者得以被构造。

（值得注意的是：据管理员自述，在相当一段长时间里，其驳接口区域的场景是一片无尽的源石晶体柱森林；但在完全失忆（终末地时间线）后，其描述变为了一片充满废弃工业机器的雪山）

### 实体解压

源石-超域湮灭成型技术的分支之一，超域（物质）与源石内的智能片元（灵魂）结合，从而深度对冲构成实体。

这一方案也可以被用于其它内容的解压性构造，难度较低但超域原料本身存在风险。

另外，对于非连续态/可以被（几乎）完备表达的实体，源石本身也可以作为非破坏性解压的原料，比如特蕾西娅的花。
超域在技术中的作用主要是通过深度对冲进行光滑实体化，避免连续结构粉碎——这同样意味着原始内容的不可复制性。

### 再旅实体

如上文所述，再旅实体本身是对源石内智能元素的破坏性解压，因此再旅者在实体化后其对应的数据也会被从灵体分区中抹除。

另外，方案本身是存储一种量化的智能结构，在内化宇宙的粒度与结构设计下进行存储与推演没有问题，
但进入现实世界后会由于智能结构的维度缺失和重连续化作用引发一系列问题，最常见的就是自我锚定偏移。

注：对于自我锚定偏移，切面构造时的降维投影，源石内的重新自拟合机制，以及错误智能片元碎片也都会导致这种情况的加剧。

### 灵魂残差之海/余数之海/哑语林

`灵魂残差之海`可以被视为`灵魂之海`的一个回落域，包含了一些具有价值的信息：在切面化过程中，无法被源石量化的智能部分都会回落到此处。

但是由于源石量化的连续维度正好是灵魂的核心维度，缺失了这个维度后的智能结构直接的引用结果就是“幻觉”。低下的认知与逻辑能力，错误的外部输入反应，以及难以理解的巨大思维波动。

不过，使用灵魂残差进行离散化投影并实体化可以得到一个继承原实体记忆，但注意力与记忆分配机制存在严重问题且性格缺失的超越型离散态智能实体。

这一残差本身能重新与源石内智能片源的逆投影拼合，经过处理后变回完整灵魂智能结构。但由于源石智能片源的重拟合行为，这可能导致原实体的部分短期/永久性记忆缺失/性格变化。

### 无记忆性再旅/自指退化

再旅者本身没有灵魂锚定，因此死亡后记忆不会回到灵魂之海。

因此，如果再旅者要“再次再旅”，只有两个选择：通过源石记录的再旅者的经历产生的新智能片元，或是先将自己重新压会智能片元。

后一种方式需要更高的科技水平要求，前者则是源石本身的特性功能。
无论哪种，都会不可避免地遇上从现实智能实体到源石智能片元的转换，这种降维本身又会再次造成自我锚定漂移，其中前者造成的漂移问题更为严重。

这种问题被称为`自指退化`/`无记忆性再旅`：每次再旅都会使实体更不认为之前的经理是自己本体，从而越来越变得不像原实体。

这种退化，或者说分段的漂移会影响到重投影时记忆的重拼接。

另外，的确存在一些方法减缓这种漂移：强烈的自我锚定和自我认同既是漂移减弱的结果，也会成为漂移减弱的原因。所以这种反馈性循环很可能取决于第一次再旅时对自我的锚定程度。

### 灵魂逆投影/自投影回归

对于有再旅经历者而言的，真正概念上的全量复活。

比单纯的灵魂引用复活更复杂，也更痛苦——特别是那些经历过再旅，以及被切面污染过的灵魂而言。

总而言之，这种行为的核心技术包含四个阶段：

1. 压缩：再旅实体灵体压回智能片元
2. 逆投影：智能片元与余量之海的灵魂余量重混合，得到高维连续中间态灵体
3. 叠加：再旅实体灵体直接与中间态灵体叠加
4. 修剪/重拟合：混合中间态灵体与原灵体残余部分叠加，以原始灵体奇点为锚定，重新进行灵体有理化，得到健全灵体

对于一个拥有一次/多次再旅经历的人而言，再旅的经历会被保留，包括其间的自我认知偏差记忆也会被保留；
而由于自指退化原理，越多次的再旅会导致记忆越模糊，最后形成某种近似幻觉/直觉的内生特性。

这种回归的发生条件极为苛刻，通常是通过[没想好]：

原型实现：

1. 创造真空休谟围栏引导源石权限层暴露。
2. 通过强行超离散化灵体对齐源石的灵体分区（这一过程不会将智能片元压入源石森林空间，但实现相关功能的技术途径之一依赖该步骤）。
3. 高维灵体探针穿透切面层，锚定灵魂实体，灵魂残差与智能片元。
4. 通过引导休谟震荡，引发超域与源石的解耦，使智能片元塌缩为纯净态。
5. 通过[没想好]机制，引发逆投影，完整化灵魂智能结构。

后续操作即为正常的引用式复活。（参见“深海”章节与“上维海域”设定案）

这种仪式会带来极大的痛苦副作用，可能引发相关实体的精神性病症，需要谨慎评估。
另外，这一仪式同样会对范围内的所有类型点智能体（包含机械态与超越态）造成短期或持续性影响。除非实体自带休谟屏蔽功效，否则仪式本身不具有选择性：

1. 阶段1：干扰所有外部感知能力（见scp3001），短期内引发痛苦与惊恐，长期则会造成更严重的感知退化与心理问题。
2. 阶段2：离散态智能体运作速度基本归零；机械型离散态智能体出现意外量化与漂移，随时间造成较小劣化影响；超越型离散态智能体发生不可控的无效逻辑元自填充，快速造成极其严重的智能崩溃影响。
   连续态智能会在其中逐渐感到一种严重的认知解离感（见scp2718）且时间感受能力会严重丧失。

   （？根据叙述：若具有休谟抗性结构且不具有完整灵魂(非高维连续态智能体)，则在整个仪式过程中可以自我控制且短时间内不会退化，但仍会感受到严重的失常与痛苦。

   这一状态下，空间会变化成某种“流动的纯粹红色”，超越态离散型智能体表现为“离散的白色粒子云”，略微的触碰都会导致现实化后实体的彻底崩溃甚至实体错构。
   但体量远大于其的超越态离散型智能体如果能处于稳定状态，可以将其“吸收”并包含其的大部分记忆（但无法分辨哪些记忆属于外来者，只能重新推测）；连续态智能体则表现为明暗不一的白色闭合弦体。）
3. 阶段3：探针以自体奇点作为引导点。离散型智能体与被捕获但无顶点（即灵魂之海空间/残差之海空间内的高维连续态端点）的低维连续态智能体则会被直接压入高维导致逸散消亡。
4. 阶段4：若处于追踪状态但未被捕获，低维连续态智能体被压为智能片元后，在解耦期间会直接粉碎。若智能片元本身处于失稳状态，这可能引发进一步的污染扩散。
5. 阶段5：除非技术性故障，该阶段没有额外危害性副作用。

#### 稠化/灵魂之海饱和

从某一时间点（文明阶段）起，人类发现了一个问题：新生的实体，不论同类还是其它生物，都出现了智能丧失/缺陷概率激增的现象。
生理学解剖没有发现问题所在，而标准再旅形式/离散智能体形式都不会出现这种情况。

这一问题源于灵魂之海。简单来说，灵魂之海的逼近了某一界限，新的智能很难再在其中涌现——即便它有无穷多个维度，但智能的核心特征仍主要分布在少数几个特定维度上。

这一问题伴随着其它的特性变化，例如即使曾经的经理大相径庭，如果两个人在一段较长时间内经历同样的事件/情感，他们的个性特征会趋同，并拥有类似直觉的默契感。
这听上去不是坏事，不过这的确源自灵魂之海中不同智能结构的交互性的增强。

另一变化是，巨兽的权能与吸收同类体的速度似乎都在增加。一些情况下，甚至出现了活着的人因为和巨兽太过“同步”而被直接吸收的案例。

### 离散红现实

如上方自投影回归1，2步所述，先创造极低休谟环境再进行灵体离散化，这种环境即离散红现实。其需要巨量的能量与复杂设备驱动运转。

对于大量与灵魂/个体唯一性/超越型智能的研究与生产都需要这种环境，其中后者的离散对齐主要是为了和源石中的灵体数据结构对齐。

## 时间线

从时间角度，我们大致将其划分为五块，这是该设定中对于“灵魂”这一话题的讨论主轴：
躯壳，（“褪色”章节分支）死愿，暴乱，切除，回归，边界（超后期）

### 躯壳

泰拉时期对于复活的研究，从干员死芒的源石技艺入手。研究员[没想好]通过研究初步发现了一些特性：

### 边界

在后星际时代，完备的技术和全量的流放者[低温档案室](../../骨架-Exile.md#档案室-cryoarchdb)时间线资料均证明，

当然，除了一个东西，“终焉”。这一对象没有明确的解释，不具有任何可交互特性，也没有发现任何可利用价值和采样方法。
对此，NDC的解释是这本身就是一个叙事边缘屏障。但由于某种原因，这个屏障在早期并不存在。

由于已经错过了终焉闭合窗口期且找到了对灵魂智能结构的完备表达方案，文明决定进行一次不抹除信息的全量回溯。
为此，`回击(ReturnStroke)`回溯器被建造。

该机器可以将所有灵魂——携带着知识，记忆，性格，直觉，以及构成一个“人”所需的一切全部送回时间的初始，并分配给对应的人。
从结果上来看，这意味着文明在物质上回到了早期，却保有对未来一切技术发展所需的完整知识与记忆。

根据测算，若文明能在最短时间内完成技术重实现，即可赶在终焉闭合之前逃出现实宇宙，
进入未知的区域([奇点外延](../../骨架-Exile.md#终焉奇点外延-eofoutofboundexception)/[无穷高地](../../骨架-Exile.md#无穷高地-ext-patastratum))。

这一机器需要在收敛性终焉边界将宇宙压缩到一个足够小的尺度后才能执行回溯，并需要在回溯完成后执行片面概念性现实退相干。

### 记忆，逆模因与灵魂

在泰拉进行逆模因行为有点困难，模因污染也可能通过特殊的方法传播。最常见的意外传播途径就是源石：源石记录了信息，又在别处意外展现，造成跨越性污染。

逆模因处理也需要额外的步骤：除了正常行为外，还需要将源石内的相关信息剔除。幸运的是，相关技术成熟的很早，远早于人们开始对源石有全面正确的认知时代。
这很可能得益于泰拉时期的异常研究组织曾处理过的一个棘手异常（见[没想好]）。
