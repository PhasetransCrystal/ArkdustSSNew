# 拓扑休谟学

传统休谟学将`休谟指数`描述为一个一维量，用于表述某点的现实程度，高休谟可以影响低休谟现实。

义休谟的归一化自然对数`休谟级量`存在：`Lh = ln(Ih/100)`，即标准现实下`休谟级量`为0，当指数趋向于0时级量趋向于负无穷。
作为参照，标准红现实(以`休谟指数`3.2计算，原文中的0.032疑似采用的是是归一化休谟指数标准)的`休谟级量`大约是-3.4。

基于`休谟级量`，存在一系列特殊特性：

现实扭曲可以按其分量尺度展开为谱：取休谟频`f`为扭曲周期长度的倒数，该尺度上的扭曲强度为振幅`A(f)`，则`休谟级量`可以表示为各休谟频分量与对应振幅的平方的积的积分，即

`Lh = ∫₀^∞ f·S(f) df`

其中 `S(f) = |A(f)|²` 称为休谟谱密度。

对于大部分宏观对象，或者说“自由休谟场”(例如环境、异常)，其谱是连续的。
当休谟被束缚于某种结构中(例如φ子)，谱塌缩为一组离散谱线，上式退化为 `Lh = Σ fₙ·|Aₙ|²`

"频率""波长"只是借用的分解手段，不意味着休谟本身具有波动性。
它表示同一处现实扭曲可以在不同尺度上拆开，各尺度具有独立的强度：低频对应大尺度、粗粒度的现实偏移（如天灾、地区性异常），高频对应触及物质结构与信息层的精细偏移。
频率加权意味着越精细的扭曲，对现实程度的贡献越大。

对于大部分常规的异常，仅使用标准的`休谟指数`足以用于锚定事件异常特性。但对于源石/超域这类极其精密的造物(特别是源石)，休谟本身的频率分布就会影响其工作状态。

-----

在常态现实下，`休谟谱密度`在`休谟频`谱轴上以`f=0`为中点呈正态分布，且标准差较小[待补充]。常规表述中所说的“低休谟空间” “高休谟空间”通常不改变中点位置。

高/低频休谟天然存在向外与向内的两种平衡趋势，分别用于维持住空间与内在的平衡：

- 外平衡-空间均质化/梯度流动：

  在高休谟对象可以改变低休谟对象的同时，高休谟空间本身也具有自发的向低休谟空间流动，从而抹平休谟空间梯度的趋势。
  这表现为标准红现实对外部侵入物质的缓慢溶解，或是现实扭曲者自身随时间的缓慢休谟下降。

  这一过程的发生通常极其缓慢，且与两点之间的`休谟级量`差存在关联。当二者的级量差约为1.7时，休谟平衡速度达到最快；当差值更小或更大时，平衡速度又会开始减慢并无限趋近于零。
