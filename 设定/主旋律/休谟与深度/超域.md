# 超域

超域的本质是“物质” “空间”与“定义”的结合。

## 物质

超域的核心原点来自一个`发散型裸奇点(Explosive Naked Singularity)`/`裸白洞(Naked White Hole)`/`拓扑涌泉(Topological Fountain)`，
其不具有视界边界，也不会由于Eardley机制引发的无限蓝移导致视界塌缩。

其物质源尚且不明确，推测可能来自所有黑洞的连接，即`黑洞-裸白洞`配对。其不直接喷涌出物质，而是“信息与物质”的混合体，
并在某个特殊空间(暂命名“内风洞”，见下，与灰阶界面的“风洞”结构不是一个东西)内发生域化反应剥离所有信息，变为纯粹的物质。

这种物质被称为“超域凝集源质”，简单的表述是表现为纯粹的，无深度的白色发光体，具有极强的侵蚀性，详细特征见下。

但如果泄漏到现实通常会在极短时间内转换为(相对)侵蚀性较低的“超域流质”，这才是通常所指的超域物质。

不论是“超域凝集源质”还是“超域流质”都存在对物质的侵蚀作用，尤其是对于“信息”与“概念”。
此处的“信息”不指我们常规中理解的“知识”，“内容”，它更多指代的是现实物质的本身结构。但因此物质本身所存储信息的结构状态也会被改变，对外表现出所需可读内容的损坏。
因此，某种角度上，它也可以被认为是“知识”的丢失。不过，超域凝集源质的现实化过程对“信息”具有特殊的处理特性，这一特性被称为“`泛信息`投影”，见下文。

### 超域凝集源质

`超域凝集源质`是超域最标准的质能存储介质，其在常规现实中无法稳定存在，需要通过控制休谟环境来稳定。

`超域凝集源质`本身可以被视为一个异形发散型宏奇点，或是一种无结构简并态物质，表现出类似白洞的物理特征。需要注意的是：`超域凝集源质`本身其实并不包含标准`双右旋φ粒子对`，或者叫`域子对`。

对于该物质，当其进入现实空间时，由于休谟差(见下，休谟特性部分)，`超域凝集源质`会在短时间内发生休谟平衡。这一过程将会发出耀眼白光并产生与周围信息/物质相似的物体。

具体而言，存在常量dm(`merpus木尔普斯`距离，仅与`超域凝集源质`内空间等效密度有关且只对该物质有效。由于`超域凝集源质`密度本身是是一个固定值[没想好]，dm也是固定值[没想好])。
假定某一点距离最近的超域质能粘液的理论距离为d，则存在：

- d =  dm：事件界面，在低休谟状态下是表现为的反光层，在更高休谟状态时则是光学与交互边界。
  
  这一边界并非理论上粘液本身的物质边界，但向内不可观测，所有力效果都会被传递。这表现为，任意形状的粘液视觉边界上任意一点，必定存在空间距离2dm距离上的至少一点位于与其在同一粘液连接体上/内。
  或者说，从粘液的实际物质边缘基础上向各个方向膨胀了dm距离。

  这还会引发一些奇怪的视觉现象，例如溅起一小块粘液水花就会出现大量的小球体，几乎达到了填充巨大空间范围的效果；或是粘液转变为超域流质时整个缩小一圈或小球粒子瞬间消失。
  不过，这种现象通常很难被观测到，因为可以发生衰变的高休谟状态下通常伴随着剧烈发光与物质化，无法直接看清边界。
- d <= 1.5dm：超高角动量粒子无限高势垒界面。本层表现为高亮的光球面。
- d <= 2dm：中高角动量势垒峰区域。较高角动量质能会被转换为高能质能束结构向外发射，表现为飞行到较远距离外的尘埃物质。如果能被观测，通常由于蓝移现象呈现淡蓝色。
- d <= 3dm：中低角动量势垒峰区域，较低角动量质能未达到逃逸速度，被转化为物质化粒子，表现为在物质附近根据`泛信息`构建出各种物质。

  通常情况下，小范围或少量的`超域凝集源质`只会产生一些无意义的物质增生或者灰尘，但大型结构则可以产生有一定规律但整体怪异的大型结构，甚至特殊的空间。

  观测时由于红移现象表现为红色。

整体而言，如果仔细观察，一个标准现实下的`超域凝集源质`的边缘会表现为(从内到外)：

- 白色发光光球层
- 不明显的淡蓝色层，通常很难看清或被外层的红移层染成紫色
- 红色层，相对蓝色层更易分辨但仍很难看清
- 大量物质粒子在外部飞散堆积

其会在内部休谟平衡达到一个特定分界线后整体瞬间转换为`超域流质`。

物理特性上，不建议任何人使用任何实体在常态现实下触碰`超域凝集源质`。其表层带有极强的失稳拖拽效应，会直接把物品甩飞并吸过去；
内层则存在反离心力结构与高能粒子风暴，则会将物质击碎。

- 1rs'：视界面：因果底界，质能只出不进，无法穿过，理论上应该是红移现象导致的黑/暗红色。
