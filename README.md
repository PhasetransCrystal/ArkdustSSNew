## [根目录(Exile)](Exile.md)

核心设定，即流放者系统。该设定(待拆分)的边界是规定时间，空间的独立边界，以及它们之间的交叉关系。

## 设定

设定部分是对该世界观运行框架与探讨方向的计划，并非直接面向读者的内容。

- [演绎者](设定/演绎者.md)：8位核心人物/实体/对象，代表着对世界的8个认知方向。
    - [同一性](设定/演绎者.md#同一性内我)：针对何为“自我”的讨论。祭司-信息/技术，侍卫-意志，圣母-记忆，先知-灵魂/主体。
    - [二相性](设定/演绎者.md#二相性外物)：针对何为“世界”的讨论。史官-观察/认知，行刑-存在，异端-现实，遗物-叙事/逻辑。
- [六权柄](设定/六权柄/权能持存.md)：六位演绎者（先知/史官之外）留下的意志之物，是相关讨论方向上最直接的异常呈现。
- 十一象征：魔法元素论，同时也是现实关系结构/物质特性的象征。
- [休谟与深度](设定/休谟与深度/本体与休谟学概论：休谟，深度，现实.md)：本体与休谟学，关于异常与深度论的理论模型，以及超域与源石的特性。
- 间奏：某些较小设定，常用于描述地区发生的异常/事件，不对整个剧情造成巨大深远影响。
- 构成：在这一切开始之前，世界本来的样子。场景预设，阵营预设，重要人物预设等。

## 剧情

面向读者的可读内容

- 篇章：剧情文本，根据所属归档组织分类。
- 档案：解释性内容，独立陈述，或者纯整活。

## 美术

- 符号：所有象征性内容，例如logo，设计稿等。
- 映像：海报/场景等设计成品内容，通常会被对应的剧情内容仓库引用。

## 其它

- 待归档：哎，我有一个点子。各种设计思路方面的内容，写了一点但还没写完的，写完了打算针对性改进的都会丢里面。
- 杂物：一些顺便用到的小玩意。
- 规范：一些对于表现形式的小规则，主要留着给自己看怕忘了。
