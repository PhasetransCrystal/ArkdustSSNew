# 休谟图表样式

机读版本为同目录 `hume-chart-theme.json`。本页是它的使用说明。所有数值取自 `tools/休谟制图器.html` 的 SVG 生成代码，括号内 `L` 加数字为该文件的行号。原 HTML 未修改。

## 适用范围

用于画独立 SVG 的小函数图，使其与休谟制图器输出风格一致。只沿用样式，不沿用休谟谱的函数、坐标含义和文字内容。页面外壳的颜色不属于 SVG，只在 JSON 的 `ui_chrome_reference` 中备查。

|---|---|---|
| 主曲线（distribution） | `#3A1466` | L54 |
| 次曲线（orbit，虚线） | `#B49CE0` | L54 |
| 界线默认色 | `#777777` | L495 |
| 坐标轴、刻度 | `#111111` / `#111` | L390, L392 |
| 全局文字 | `#161016` | L371 |
| 网格 | `#E1E1E1` | L381 |
| 基准线 | `#9B91A5` | L383 |
| 基准线标签 | `#80718C` | L396 |

| 标注主文字、点、引线 | `#000000` | L308-311 |

| 背景、标题描边、峰值点描边 | `#ffffff` | L371, L375, L389 |

曲线颜色必须是 `#rrggbb` 六位写法(L188, L195)。

## 二、背景与布局

- 背景:整幅白色 `<rect width="100%" height="100%" fill="white"/>`(L371)。
- 绘图区默认 960×480,范围 x∈[-3,3]、y∈[0,160](L61)。
- 边距:左 72、右 36、上 140、下 85(L239)。标注和图例会追加留白,算法在 `layoutOf`(L265-278)。独立 SVG 没有标注和图例时,可直接用这四个边距。
- 曲线、网格、填色放进绘图区的 `clipPath`,坐标轴和文字在 clip 之外(L380, L390)。

## 三、网格、轴线、刻度

- 网格:`#E1E1E1`,线宽 1,每个刻度一条竖线、一条横线(L381)。
- 轴线:`#111111`,线宽 3.5,一个 path 画出竖轴加横轴,过 (0,0),零点超出范围时贴边(L378, L390)。
- 刻度短线:长 6,`#111`,线宽 1.5(L392-393)。
- 刻度间隔:约 7 格,步长取 1、2、2.5、5、10 乘 10 的幂中第一个够大的值(L295)。
- 基准线:`#9B91A5`,线宽 1.3,虚线 `5 5`(L383)。

## 四、字体与字号

字体族:`Microsoft YaHei, Noto Sans CJK SC, Arial, sans-serif`(L371)。

| 元素 | 字号 px | 位置 | 来源 |
|---|---|---|---|
| 主标题 | 最大 48,粗细 900,白色描边 7,`paint-order="stroke fill"` | x=W/2, y=70 | L375 |
| 副标题 | 最大 23 | x=W/2, y=82 | L374 |
| X 轴标题 | 15 | 绘图区中心,下沿 +52 | L394 |
| Y 轴标题 | 14 | 绘图区左缘,上沿 -22 | L395 |
| 刻度数字 | 12 | X:轴下 24,居中;Y:轴左 12,右对齐,下移 4 | L392-393 |
| 基准线标签 | 11 | 右缘 -5 | L396 |
| 图例 | 16 | 见 JSON `legend` | L398-410 |

标题字号会自动缩小:取 `min(最大值, (W-90)/文字宽度)`,ASCII 字符按 0.63 宽,其他按 1(L372, L296)。先画副标题,后画带白描边的主标题,使主标题压住副标题上半部(L373)。

## 五、曲线

- 线宽默认 2.5,`fill="none"`,`stroke-linejoin="round"`(L52, L363)。
- 线型:实线无 dasharray;虚线 `9 6`;点线 `2 5`(L314)。
- 采样:按绘图宽度取 500 到 1800 个点,再在像素误差超过 0.5 处递归细分,直到间距小于 0.15px(L318, L337-343)。
- 峰值点:半径 4,与曲线同色,白色描边 1.5(L389)。

绘制顺序:网格 → 基准线 → 填色 → 界线 → 次曲线 → 主曲线 → 峰值点 → 坐标轴 → 标注 → 刻度与文字(L381-396)。

## 六、填色

默认关闭,不透明度 0.25,位于曲线下方,颜色与所属线条相同(L51)。花纹填色使用 10×10 的 pattern,线宽 1.5(L139-149):

- 右斜线:旋转 45°。左斜线:旋转 -45°。
- 斜网格:旋转 45° 的十字。竖网格:不旋转的十字。
- 点阵:圆心 (5,5),半径 1.8。

## 七、标注样式

(L70, L298-311, L239)

- 点:半径 3.5,黑色。
- 引线:黑色,线宽 1.75,从点画斜线到绘图框边缘,再向框外水平延伸 24。
- 主文字:黑色,字号 32,在引线上方。无副文字时垂直居中于引线。
- 副文字:`#808080`,字号 16,在引线下方。
- 行距 1.3 倍字号,引线与文字间距 10。文字一律在绘图框外。

## 八、无文字小图模式(small)

(L108, L347-366)

每格是正方形面板,默认 240,内边距 24,格间距和外边距 16。只含基准线、填色、界线、曲线和坐标轴。没有标题、网格、刻度、文字、标注和峰值点。适合只看形状的缩略图。

## 九、使用建议

1. 生成 SVG 时先按 JSON 的 `canvas`、`font`、`axes`、`grid` 搭骨架,再放曲线。
2. 多条曲线用 `#3A1466`(实线)和 `#B49CE0`(虚线)区分。需要更多颜色时,在此基础上另行约定,并记录在本文件。
3. 轴标题和基准线标签的文字是休谟谱专用,复用时替换文字,保留位置和字号。
4. 本主题没有读取 `annotationExtra`、`legendHeight`、`fmt` 的实现,也没有读取 `baseline` 以外的谱组预设颜色。涉及标注留白或数字格式时,需要再去原文件查看对应函数。
