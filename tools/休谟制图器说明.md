# 休谟制图器说明

## 启动与文件

双击同目录的 [休谟制图器.html](休谟制图器.html)，使用现代 Chrome、Edge 或 Firefox 打开。地址栏可以直接是 `file:///D:/Arkdust/新版设定集/tools/休谟制图器.html`。

- 单一 HTML，CSS、JavaScript 全部内嵌；没有 CDN、网络字体、外部图片或第三方库。
- 不需要 Node、Python、安装包、命令行或本地服务器。这些环境仅在开发测试中使用，不是运行依赖。
- 只在本机计算；不会上传配置或图片。浏览器下载策略可能要求确认保存位置。
- 本工具是制图辅助，不修改任何设定正文。

## 点与引出线标注

普通图和双图的“标注”面板支持新增、删除、隐藏最多 30 条标注。标注会一同写入 SVG、PNG、JSON 和可选的本地记忆；小图模式隐藏全部标注并禁用新增和图中选点，切回后恢复。

1. 点击“＋ 添加标注”，填写点的 x、y，或点击该条的“图中选点”后在绘图区点击。双图中点在左图还是右图由点击位置决定，并写回“所属图”。再次点击选点按钮或按 Escape 取消。
   点击位置与某个可见谱组的曲线顶点（峰点 `(p, Yf)`，对数图为 `ln(Yf/100)`）在屏幕上相距不超过 12px 时，自动改写为该顶点的精确坐标；有多个顶点时取最近的。按住 Alt 点击则不吸附。吸附只写入一次数值，不与谱组绑定，之后修改谱组参数，标注不会跟着移动。
2. x 为实际谱坐标 u；y 为该标注所属图的显示轴值。对数轴上直接填 `ln(y/100)`，例如基准强度填 `0`。切换纵轴模式不会换算标注数值。点无需位于曲线上。
3. 引出线只有向左、向右两种，统一从点水平延伸到绘图区边框，再在框外留一段水平线。文字写在这段框外水平线上：主文字在线上、副文字在线下，不写进绘图区内部。副文字留空时，主文字改写在线端之后，与引出线竖直居中（多行时整体居中）。
4. 主文字为黑色，副文字为灰色。两项均可留空，均可多行（最多 8 行，每行最多 60 个字符，合计最多 480 个字符）。主文字与副文字字号分开设置（8–48 px，新标注默认主文字 32 px、副文字 16 px），可调整点半径。
5. 画布会按引出文字的宽度在左右自动加边；上下只在文字块超出绘图区上沿或下沿时，才补超出的那一部分，文字不会被裁掉。标注位于图中部时，增加副文字行数不会拉长画布。主／副文字末尾的空行会被忽略，不参与排版。点的 y 超出该图纵轴范围时，点会被裁剪，画布不因此扩展。标注之间不自动避让，重叠时请自行错开坐标或方向。

新配置为 **version 6**。version 1、2、3 的完整配置会在校验后迁移：补独立对数纵轴范围，并把旧标注的 `dx`、`dy`、`length` 丢弃（引出方式已统一，这些偏移不再有意义），补副文字字号与所属图。version 4 迁移时补 `legendFontSize: 16`；version 1–5 迁移时为每条曲线和界线补上关闭状态的一侧填色。已有标注保留原字号。移动工具路径后，浏览器可能不能读取旧路径的本地记忆，已有 JSON 备份仍可导入。

## 界线与小图

- **自定义界线**：可添加／删除最多 20 条，分别控制显示、颜色、线宽、实虚线。支持 `y=2x+3`、`y=-x`、`y=100`、`y=0.5*x-2`、竖直线 `x=1` 和十进制负数／小数；不支持函数、幂、除法或代码。采用正则语法解析，不执行表达式；系数绝对值不超过 `10^12`。非法输入保留上一张有效图并提示，错误界线可直接删除。
- **坐标语义**：表达式的 x 是谱坐标 u，y 是当前显示纵坐标。对数模式下 `y=2x+3` 就是 `ln(表征量/100)=2u+3` 的直线，不会对界线再取对数。双图中同一条界线分别按左图线性轴和右图对数轴解释，两侧含义不同。普通图、双图和小图都会裁剪界线。
- **一侧填色**：每条界线、每个谱组的分布与轨道曲线都可单独开启“一侧填色”，设置颜色、不透明度（0–1，默认 0.25）、填充侧和花纹。填充侧为下侧或上侧；竖直线 `x=常数` 时自动改称左侧、右侧（下侧＝左侧，上侧＝右侧）。花纹可选纯色（默认）、右斜线、左斜线、斜网格、竖网格、点阵，花纹线也使用所选颜色和不透明度。填色范围裁剪到绘图区，只在对应的线或曲线显示时绘制，画在网格与基准线之上、自定义界线与谱组曲线之下。曲线的填色区域按曲线与绘图区上沿或下沿之间封闭。
- **双图模式**：顶部选择“双图 · 线性 + 对数”，同一组谱在一幅图里左右并排，左图纵轴为线性表征量 y，右图为表征级量 ln(y/100)，横轴相同。两侧纵轴范围各自独立，不互相换算。双图下纵轴模式选择被禁用，左轴恒为线性。
- **小图模式**：顶部选择“小图”，每个至少开启分布或轨道的谱组一格，按列表顺序竖排，共用坐标范围。每格仅含已开启曲线、x/y 轴、已启用的基准线和界线；不显示文字、标题、刻度数字、图例、网格、峰点或标注。普通图的这些设置不会被清除，切回即可恢复。
- 每格边长可设为 `120–1000 px`，每格为正方形；总高度为 `组数 × 每格边长 + (组数+1) × 16 px`，宽度为每格边长。无可见组时界面给出提示，图内不添加文字，导出为一格高度加 32 px 的空白图。
- PNG 使用实际 SVG 总尺寸乘以倍率；单边超过 16384 px 或超过 4000 万像素会提前拒绝并提示缩小尺寸／倍率，仍可导出 SVG。
- version 2 引入 `layout`、`panelHeight`、`boundaries`，version 3 引入 `annotations`，version 4 引入 `logYMin`、`logYMax`，version 5 引入 `legendFontSize`，version 6 在各线条样式中引入 `fill`（`show`、`color`、`opacity`、`side`、`pattern`）。旧配置迁移时补齐缺失字段；旧标题、参数、范围、样式不丢失。各版本均严格校验完整字段。

快速检查：已在 `file://` 浏览器验证合法／非法表达式、两组无文字无网格竖排、1100×528 SVG 与 2200×1056 PNG、正常模式往返保留设置、错误输入保留旧图、旧配置迁移及超大画布拒绝。未重跑全部历史测试或跨浏览器测试。

## 操作

1. 默认显示一组**基准现实**。在“谱组”中选择预设，再点“＋ 添加组”，可叠加至 20 组。各组可删除，也可全部删除以保留空坐标图。
2. 各组分别编辑名称、`Lf`、`Yf`、`Delta`、`sigma`。参数变更即时更新图与 `p`、`Ih`。
3. 分布与本征轨道有独立的显示开关、颜色、线宽及实线／虚线／点线。默认分布为深紫 `#3A1466`，轨道为浅紫 `#B49CE0`。红现实预设同样使用紫色系，可自行调整。两条曲线各有独立的一侧填色设置，见“界线与小图”中的一侧填色说明。
4. 主标题、副标题均为可编辑单行文本。先绘制淡紫副标题，再绘制带白色粗描边的主标题；主标题压住副标题上半部的重合区域，这是有意的装饰效果。长标题自动缩小，而不是换行。
5. 宽高是**单个坐标轴绘图区**的尺寸，不是整张导出图的尺寸。标题区、轴标签、图例和引出文字的边距由工具自动累加，所以导出图会比所填宽高大。双图按两个绘图区并排计算。预览按画布宽高比等比缩小，宽度不超过右侧预览区，桌面端高度不超过窗口高度减 260px，因此大画布不会撑出屏幕；窄屏（≤760px）只限制宽度，页面纵向滚动。缩放只影响预览，导出仍按真实画布尺寸。旧配置里的宽高在迁移后按绘图区重新解释，导出图会比以前更大。
6. 网格、图例、峰点、基准线 `y=100` 分别开关。图例每组左侧两条短线依次代表分布、轨道；第二行给出 `p` 和 `Ih`。图例字号可设为 8–32 px（默认 16），行高、样线位置与参数行按字号等比缩放。隐藏曲线不会改变数学参数。
7. 输入暂时无效时显示错误，**保留上一张有效图，并禁用三个导出按钮**。修正输入后自动恢复。JSON 导入失败不会替换原配置。
8. “恢复默认画面”会立即恢复基准现实；若启用了本地记忆，也会保存此默认画面。恢复前需要保留当前工作时，请先导出 JSON。

### 坐标模式

- 横轴统一为**实际谱坐标 u**。
- 线性纵轴为“表征量 y”，默认范围 `[0,160]`。
- 对数纵轴明确标为 **表征级量ln(y/100)**，默认范围 `[-6,2]`。例如轴值 `0` 对应 `y=100`，轴值 `1` 对应 `y=100e`。
- 此对数轴不等同于正文中的 `ln(Ih/100)`，也不是 `log10(y)`。
- 单图切换纵轴模式时，切到对数会沿用已保存的对数范围，切回线性则回到 `[0,160]`；横轴与谱组不变。随后可以手动调整。
- 双图的左轴范围用“纵轴最小／最大值”，右轴范围用单独的“右图纵轴”两项。从对数单图切到双图时，原对数范围会移到右轴，左轴回到 `[0,160]`。
- “适配可见峰高”根据已开启任一曲线的组的峰高重设纵轴；双图同时重设左右两轴。不移动横轴，也不追踪轨道端部。线性上限最多为 `10^12`。峰在横轴之外时，需自行调整横轴。
- 基准线在线性模式是 `y=100`，在对数模式是 `ln(y/100)=0`；范围不包含它时自然不可见。

## 数学合同

以下是本工具采用的现象学定义。

```text
sigma0 = 1 / sqrt(2*pi)
p = Lf + atanh(Delta)

y(x) = Yf * exp( -(x-p)^2 / [2*sigma^2*(1-Delta*sign(x-p))^2] )

Ih = (sigma/sigma0) * Yf * exp(p)
```

其中 `Lf` 是中心参数，`Yf` 为峰高，`p` 是实际峰位。`sigma` 是**偏态宽度尺度，不一定是统计标准差**：

- 峰左侧的宽度尺度为 `sigma*(1+Delta)`；
- 峰右侧的宽度尺度为 `sigma*(1-Delta)`；
- 在 `x=p` 时明确取 `y=Yf`。

**Ih 使用以上用户采纳的定义，不声称等于严格逐频加权积分 `∫y(x) exp(x) dx`。** 程序不以数值积分偷偷替换它。

### 本征轨道

横轴必须使用实际谱坐标 `u`：

```text
Yorbit(u) = Ih * sigma0 / sigma * exp(-u)
          = Yf * exp(p-u)
```

因此 `Yorbit(p)=Yf`，轨道必过本组峰顶。不再给轨道额外叠加一次 `Delta` 或 `atanh(Delta)` 位移。

### 对数计算与数值保护

对数分布通过 `log(Yf)` 减去二次项，再减 `log(100)` 直接构造；不会先计算很小的 `y` 再取对数。对数轨道直接由 `log(Yf) + (p-u) - log(100)` 得到。

`Ih` 内部保留为：

```text
logIh = log(sigma) - log(sigma0) + log(Yf) + p
```

正常范围直接显示数值；过大或过小则显示科学计数形式，极端指数显示 `exp(…)`，避免不必要地得到 `Infinity` 或 `0`。其标签仍是 Ih，而不是纵轴的表征级量。

渲染采用全域采样、峰附近两侧局部加密、显式峰位采样、可见纵轴边界交点采样及曲率自适应细分。即使极窄峰落在均匀采样点之间，也不会整座漏掉。曲线使用 SVG `clipPath` 裁剪到绘图区。超出图外很多的纵向坐标做有限饱和，仅影响不可见路径部分，不改变图内函数定义。

极窄峰的可见宽度可能低于一个像素，因此会成为尖线；这是画幅分辨率限制。可缩小横轴范围来检查细节。接近机器精度时，峰附近的不同实数可能映射到同一个浮点数，工具不能消除此限制。

### 合法输入与工程边界

- `Lf`、`Yf`、`Delta`、`sigma` 必须是有限数字；`-1 < Delta < 1`、`sigma > 0`、`Yf > 0`。
- `Delta=+1/-1` **仅是极限，不能直接绘制**。不自动把端点改成其它值。
- 有效侧宽必须是正的有限浮点数；峰位及 `logIh` 也须有限。因机器浮点上下溢导致这些派生量不可用时，明确拒绝。
- 绘图区宽为整数 `300–2400`，高为整数 `200–1800`；线宽 `0.25–12`。整张画布在此基础上自动加边，因此导出尺寸可以超出这两个范围。
- 横轴、线性纵轴和对数纵轴的上下限都须在 `[-10^12,10^12]` 内且严格递增。跨度至少为 `10^-12 * max(1,abs(下限),abs(上限))`；线性纵轴（含双图左轴）下限不能为负。
- 上述尺寸、坐标和组数限制是制图工程限制，不是世界观中的物理约束。
- 图例高度由组数决定并自动加到画布底部，不再要求绘图区预留固定高度。
- 主标题最多 80 个 UTF-16 码元，副标题 100，组名 40。不接受换行、控制字符和不合法的 XML／Unicode 字符。合法 emoji 可用，但字体支持依赖系统。
- 图例长名称会截短并添加省略号；完整名称仍在控件和 SVG 的悬停提示中。

## 预设

| 预设 | Lf | Yf | Delta | sigma | 备注 |
| --- | ---: | ---: | ---: | --- | --- |
| 基准现实 | 0 | 100 | 0 | sigma0 | p=0，Ih=100 |
| 源石 | 0 | 100 | 0.8 | sigma0 | p=ln(3)，Ih=300 |
| 超域 | 0 | 100 | -0.8 | sigma0 | p=-ln(3)，Ih=100/3 |
| 红现实 | 0 | 3.2 | 0 | sigma0 | 低休谟示例，Ih=3.2 |
| 聚焦 | 0 | 400 | 0 | sigma0/4 | 缩窄、增高，Ih 仍为 100 |

源石／超域的 `Delta` 按本任务指定。红现实的具体数值、聚焦的幅度以及其它可编辑初值是**工具演示起点**，不新增或宣称替代设定正文。添加多组后请按需要设置区分颜色、标题和坐标范围。

## 导出

### SVG

“导出 SVG”保存 `休谟图.svg`。预览与导出共用同一个 `renderSVG`，不依赖屏幕截图。SVG 保留矢量曲线、文本和裁剪区域，放大不需要倍数选项。

### PNG

选择 `1× / 2× / 3×` 后点击“导出 PNG”。PNG 由同一 SVG 解码后绘入离屏画布，有不透明白底：

| 基础画幅 | 1× | 2× | 3× |
| --- | --- | --- | --- |
| 1100 × 720 | 1100 × 720 | 2200 × 1440 | 3300 × 2160 |

导出仅含图的白底、标题、坐标、曲线及启用的图例／标记，不含参数面板、按钮、状态提示或工作台阴影。SVG 和 PNG 使用系统字体，不内嵌字体；跨系统打开 SVG 时字形可能变化。若需要固定当前字形，请使用 PNG。

PNG 异步处理会捕获 SVG 解码失败、画布不可用、编码异常和空 Blob；另有解码／编码超时保护。生成期间禁用重复 PNG 导出。大画幅 3× 需要较多内存，失败时可降低画幅或倍率。导出时的配置会被快照保存，随后修改面板不会改变已经进行中的导出。

### JSON

- “导出 JSON”保存 `休谟制图器配置.json`，包含版本、标题、绘图区尺寸、模式、范围、开关、界线、标注以及所有谱组参数和样式。
- PNG 倍率和“记住配置”的选择属于工作台选项，不在图像配置 JSON 中；重新打开后倍率默认为 1×。
- 导入是**完整替换**，不是合并。接受 `version:1` 至 `version:5`（自动迁移）或 `version:6` 的完整结构，最大 1 MiB；未知或缺失字段、错误类型、非法参数／范围／样式都会拒绝，不做字符串转数字或自动夹紧。
- 推荐先导出当前配置作为模板，再编辑；数值不能加引号，布尔值用 `true/false`，颜色为 `#RRGGBB`。
- 标题和组名会做 XML 转义，不作为 SVG 标记执行；颜色及线型也不允许填入任意 SVG/CSS。

## 可选本地记忆

默认不开启保存。勾选“在此浏览器中记住有效配置”后，会将最后的有效配置写入 `localStorage`，键为 `arkdust.hume.plot.v1`，同一浏览器下次打开时尝试恢复。取消勾选会尝试删除该工具键，不清除其它站点或其它工具的数据。

`file://` 存储策略、隐私模式和浏览器权限各不相同，移动 HTML 路径也可能影响恢复。读取、写入、删除失败均显示提示但不中断绘图和导出；保存内容损坏时退回默认图。若浏览器拒绝删除旧存储，工具会提示，本次会话停止自动保存，但旧配置可能仍留在浏览器中。**重要作品请导出 JSON，不把 localStorage 当作唯一备份。**
