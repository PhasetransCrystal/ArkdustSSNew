## 一、`共轭φ晶岩`（`奥卡里特 / Окалит`）设定深挖与修正

> 该物质来源于奥卡与超域质碰撞的产物

### 1. 核心修正：微观严整晶格 vs 宏观“使用痕迹拟态”

- **物理机制对齐**：`奥卡`（`解离左旋φ子`）与`超域流质`（`双右旋φ子对`）发生吸热接触反应时，微观上左、右旋 `φ子`
  一一配对形成惰性**`共轭φ子对`**，
  锁死在正常的复杂物质晶格势阱中；但在宏观固化成形的瞬间，由于`超域流质`向 `Δ -> 0` 右移物质化时会倒吸周围环境的**
  `隐模因`**（《超域物理学》中定义的工具“第三持存/实体感知痕迹”），
  晶岩在宏观外貌上会自发长成周围人造物件的扭曲残缺形状。
- **常态随机基调**：平缓接触反应本身**不会吞噬外部实体**，超域侧在向 `Δ -> 0` 右移物质化时仅被动截获空间背景中游离的微弱
  `泛信息 / 隐模因`涨落。因此原岩结核在保留微观严整共轭晶格的同时，宏观上主要呈现**无规律的随机残缺器物拟态**
  （盲头螺栓、残缺法兰齿、无义棱台等随机拼贴）。
- **三种定向/具象化偏向条件**：
    1. **反应场地环境相似倾向**：背景隐模因涨落带有场地统计偏置，使产出晶岩在概率上轻微趋近周边环境结构（如在矿井反应室更易长出岩栓、轨扣残形，在管廊内更易长出管箍、阀轮残片）；
    2. **原料前身吞噬记忆“反刍”**：工业所用的`奥卡`与`超域流质`
       在采集前（如矿脉枯竭区或北境塌缩带）往往早已吞噬、同化过大量源石设备与人造构筑物；这些封存在原料内部的残存结构信息会在共轭成岩时被随机析出（甚至能凭晶岩长出的旧帝国零件残影反推原料矿源）；
    3. **剧烈过激反应的实体吞噬**：唯有在投料失控或界面“釜垢”破裂引发剧烈暴沸反应时，局部休谟与温度的断崖式暴跌才会越过失稳边界，直接将紧邻反应区的釜内构件或掉入物卷入侵蚀吞噬，凝结出高保真的残骸拓印晶块。

### 2. 工业工艺演进：为什么会有“屏蔽砖”与“偏谱筛”两条分支？

同一种高度惰性材料，按**晶畴取向与孔隙结构**直接分化出两大工程用途（完美契合你定的“强效休谟过滤/屏蔽结构”定位）：

1. **全频段休谟屏蔽 / 拒止衬材（`黑砖 / 哑砖`，工程代号建议 `ОК-Б`）**
    - **工艺**：将原岩破碎后高温致密烧结（闭孔、晶向随机分布）。
    - **机理**：随机取向的共轭 `φ子对`（左旋耦合正深度高频端，右旋耦合负深度低频端，叠加奥卡残留的相散射基底）对穿过的休谟波动与本征休谟梯度流形成全向阻尼散射。它
      **零能耗、高度惰性**（既不像奥卡那样吞噬源石或闪蒸，也不像超域那样侵蚀物质），是休谟泵内衬、反应釜防爆隔层与高危异常收容室“黑墙”的首选被动屏蔽装甲。
2. **特定频段休谟过滤材（`偏谱筛`滤片，工程代号建议 `ОК-Ф`）**

- **偶然发现契机**：早期试制屏蔽黑砖时，某次局部过激反应意外吞入了一截脱落的精密源石谐振波导栅格，研究员在检测这块废料时偶然发现——当晶岩内部的共轭晶轴与微孔呈现出
  **周期性定向排列**时，其不再全频段阻尼休谟，而是表现出窄带选通与移频收束效应。
- **可量化的标准化量产工艺**：由于“隐模因/记忆”本身无法定量标准化，实际工业生产反而是**先彻底消除随机拟态结构，再以标准物理参数重构周期晶格
  **：
    1. **球磨去拟态**：采用纯化增生`奥卡`与标准衰减级`超域流质`反应制得粗晶砂，经高能球磨粉碎成固定粒径的均质微粉，彻底打碎宏观随机器形与不规则气孔；
       同时通过*相关机制*对内容进行隐模因加噪平均化
    2. **定量掺杂与驻波极化烧结**：按精确质量比混入微量**固定深度 `Δ` 的标准源石晶种粉**作为成核剂，在高温重结晶炉中施加*
       *定频源石技艺谐振驻波场**。驻波场迫使重结晶过程中的`共轭φ子对`同向极化对齐，并在波节面处烧结出层间距严格可控的微孔布拉格光栅（Bragg
       Grating）：
        - **驻波波长与晶格极化倾角** $\to$ 定量决定选通中心频率 `Ls`；
        - **微粉粒度、孔隙率与叠片层数** $\to$ 定量决定通带半宽 `w`。
    3. **为什么早期受限于低 `|Lf|`、后期拓宽**：由 `Lf = ln(f / f0)` 可知，主频 `|Lf|` 每向外推移一个单位，对应的特征休谟谐振波长便按指数级缩短。早期
       **粉末压延烧结工艺**受限于球磨粒径与驻波场均匀度，微孔层间距公差较大，仅能稳定制备长波段的低 `|Lf|`
       滤片（一旦强行烧结高频细栅，晶畴相位误差会互相抵消而退化回普通屏蔽黑砖）；
       直到后期开发出 **流质-气相界面外延沉积与精密激光刻蚀叠片工艺**，才实现了中高 `|Lf|` 频段滤片的标准化量产。

### 3. 副产物与极限失效细节（可选作设定集补充风味）

- **反应界面“釜垢（`Накипь` / 灰皮）”**
  ：对应你在《源石生理学》里写的“交界面现实倒灌物质膜”。局部休谟骤降引发微量现实倒灌，在未反应的奥卡表面结出一层阻碍接触的灰白脆膜（刮下的垢片背面常带有模糊的浅表指纹或字迹残印）。生产中必须定期“刮垢”，否则膜下奥卡活性累积，一旦膜裂大面积接触超域流质会引发局部骤冷负压爆裂（俗称**
  “垢爆”**）；而派人进釜刮垢又容易带入新的隐模因杂波，构成新乌萨斯工厂里经典的“纯度 vs 安全”矛盾 *(源自子代理 `OPUS55`)*。
- **结霜特征**：由于生成晶岩的反应是吸热的，切制成的`偏谱筛`在强行压制阻带、搬移频谱时仍带有微弱的吸热倾向，高负载工作时滤片栅表面常凝结一层白霜（车间俗称“冷片”）。
- **超限冲击失效前兆**：常态下高度惰性，但若遭受跨越**失稳阈值**级别的极端冲击或强深度撕裂，晶格松动的前兆是黑砖表面残缺的拟态器形出现诡异的边缘锐化与“补全”幻象（车间保命口诀：
  **“黑砖长全，拔腿就跑”**，*源自子代理 `OPUS55`*）；彻底击穿时共轭配对解离，局部可能发生危险的**返奥卡化**
  ，或在断口析出微量负深度的**`类域源石`**晶须（扣回《源石生理学》第 108 行伏笔）。

### 4. 超限冲击解离时，多出来的`右旋φ子`去哪了？（严格粒子数守恒）

晶岩每个配对单元含 `1 个左旋φ子 + 1 个右旋φ子`。当遭受跨越**第一失稳阈值（4倍本征休谟差）**的冲击或强深度撕裂导致晶格击穿、共轭键断裂时，两侧
`φ子` 的去向严格分流：

- **`左旋φ子`去向**：一部分维持单子解离态，在断口发生危险的局部**返奥卡化**
  （重获链式吞噬源石活性）；另一部分因保留了此前被超域侵染的负深度倾向而两两重配对为左旋对，在裂纹处析出极微量的负深度**
  `类域源石`**暗色晶须（直接对应《源石生理学》中的制备母料伏笔）。
- **多出来的`右旋φ子`去向（两条路径，解释为何没留下稳定“反奥卡”）**：
    1. **主流路径——毫秒级同旋复合为次生`超域流质`并瞬时耗散**：由于孤立的`解离右旋φ子`
       天然耦合负深度端，在常态正休谟环境中能垒极高、无法稳定存留，绝大多数游离出的`右旋φ子`会在毫秒内两两同旋重配对回
       `双右旋φ子对`——即在击穿断口处渗出一股极寒的**微量次生`超域流质`白雾**。这股流质暴露在外部高休谟现实中会立刻发生二次
       `Δ -> 0` 平衡与概念侵蚀（抹平紧邻线缆与传感器的数据结构，并在断口重新结出一层灰白倒灌杂质膜）；
    2. **次要路径——孤立单子微秒级闪冷湮灭（“反奥卡”猜想的实验来源）**：极少数被高速剪切孤立隔开、来不及配对的单个`右旋φ子`
       ，会在微秒级时间内被环境休谟直接冲刷湮灭，仅释放出一次微弱的宽谱吸热闪冷脉冲与普通惰性微尘。
       物理学家正是在晶岩击穿实验的超高速波谱记录中捕捉到了这道瞬态谱线，才在理论上推演出“极低休谟下或可稳定存在解离右旋φ子物质（即
       `反奥卡`）”的猜想，但在常规环境下始终无法截获实物。
